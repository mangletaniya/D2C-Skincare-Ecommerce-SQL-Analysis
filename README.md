# 🧴 D2C Skincare E-Commerce SQL Data Analysis

## 📌 Project Overview

This project focuses on analyzing a Direct-to-Consumer (D2C) skincare e-commerce business using MySQL.

The objective is to explore business performance, customer purchasing behavior, product sales, profitability, inventory, returns, and customer reviews through SQL queries.

The project includes 35 SQL analysis queries using Joins, Aggregate Functions, CTEs, Window Functions, and Date Functions.

## 🛠️ Tools & Technologies

* MySQL
* SQL
* Relational Database
* Joins
* CTEs
* Window Functions
* Aggregate Functions

## 📂 Dataset

The dataset contains six relational tables:

1. Customers
2. Products
3. Orders
4. Order_Items
5. Returns
6. Reviews
